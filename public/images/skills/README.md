# Skill Logos Directory (`/public/images/skills`)

Put your exact technology logo SVG files in this directory.

Each logo is fetched by Next.js from `public/images/skills/<filename>` as defined in `data/skills.ts`:

| Technology | Expected Filename |
|---|---|
| Python | `python.svg` |
| Pandas | `pandas.svg` |
| NumPy | `numpy.svg` |
| Jupyter | `jupyter.svg` |
| PyTorch | `pytorch.svg` |
| scikit-learn | `scikitlearn.svg` |
| Hugging Face | `huggingface.svg` |
| TypeScript | `typescript.svg` |
| Next.js | `nextdotjs.svg` |
| React | `react.svg` |
| Git | `git.svg` |
| Docker | `docker.svg` |
| PostgreSQL | `postgresql.svg` |

To change or update any logo, simply overwrite the corresponding file in this folder (e.g. replace `python.svg` with your preferred SVG).
